# Food Corner – Restaurants & Cafes Website

## 1. Introduction

Food Corner is a simple and attractive restaurant and cafe website developed using HTML and basic CSS.

This website is designed to display restaurant details, food items, cafe menus and contact information. It provides a simple and user-friendly design for visitors.

## 2. Objectives

- To create a simple restaurant and cafe website.
- To display different food and cafe items.
- To provide restaurant information.
- To display contact details.
- To design an attractive webpage using basic HTML and CSS.

## 3. Technologies Used

- HTML5
- Inline CSS
- Visual Studio Code

## 4. Website Features

- Attractive homepage.
- Restaurant and cafe welcome section.
- About Us section.
- Restaurant food menu.
- Cafe menu.
- Why Choose Us section.
- Contact information.
- Simple and attractive colour combinations.

## 5. Website Sections

**Home:** Displays the welcome message and website name.

**About Us:** Provides a short introduction about the restaurant.

**Our Special Menu:** Displays different food items with their prices.

**Why Choose Us:** Explains the special features of the restaurant.

**Contact Us:** Displays the address, phone number and email address.

## 6. HTML Elements Used

- html
- head
- title
- body
- div
- h1, h2, h3
- p
- ul
- li
- center
- hr

## 7. How to Run the Project

1. Open Visual Studio Code or Notepad.
2. Create a new file named `index.html`.
3. Write or paste the HTML code.
4. Save the file.
5. Open the file using Google Chrome.
6. The Food Corner website will be displayed.

## 8. Expected Output

A simple and attractive restaurant and cafe website displaying the homepage, about section, food menu, specialities and contact information.

## 9. Conclusion

This project helps in understanding the basic concepts of HTML and CSS. It demonstrates how to create a simple restaurant and cafe website using basic HTML elements and styling.

The website is easy to understand, beginner-friendly and suitable for learning basic web development.
