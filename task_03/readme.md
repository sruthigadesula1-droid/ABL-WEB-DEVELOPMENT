# Learn Hub – Online Learning Platform

## 1. Introduction

Learn Hub is a simple and attractive online learning platform website developed using HTML and basic CSS.

This website helps students explore different courses and improve their knowledge and skills through online learning.

## 2. Objectives

- To create a simple online learning website.
- To provide information about different courses.
- To encourage students to learn new skills.
- To display the benefits of online education.
- To understand basic HTML and CSS concepts.

## 3. Technologies Used

- HTML5
- Inline CSS
- Visual Studio Code

## 4. Website Features

- Attractive homepage.
- Welcome section.
- About Us section.
- Popular courses.
- Why Choose Learn Hub section.
- Learning benefits.
- Contact information.
- Simple and attractive design.

## 5. Available Courses

1. Web Development
2. Python Programming
3. Artificial Intelligence
4. Communication Skills

## 6. HTML Elements Used

- html
- head
- title
- body
- div
- h1, h2, h3
- p
- ul
- li
- center

## 7. How to Run the Project

1. Open Visual Studio Code or Notepad.
2. Create a new file named `index.html`.
3. Copy and paste the HTML code.
4. Save the file.
5. Open the file in Google Chrome.
6. The Learn Hub website will appear.

## 8. Expected Output

The website displays a homepage with a welcome message, course details, information about online learning, learning benefits and contact details.

## 9. Conclusion

This project helps us understand the basic concepts of HTML and CSS. It demonstrates how to design a simple online learning platform using basic HTML elements and styling.

The website is beginner-friendly, easy to understand and useful for learning web development.
