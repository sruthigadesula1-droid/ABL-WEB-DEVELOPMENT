# College Information and Admissions Website

## 1. Introduction

The College Information and Admissions website is a simple and attractive webpage developed using HTML and basic CSS.

This website provides information about the college, available courses, admission details and college facilities. It helps students understand the college and its educational opportunities.

## 2. Objectives

- To create a simple college information website.
- To provide details about the college.
- To display available academic courses.
- To provide admission information for students.
- To display college facilities.
- To understand basic HTML and CSS concepts.

## 3. Technologies Used

- HTML5
- Inline CSS
- Visual Studio Code

## 4. Website Features

- Attractive homepage.
- Welcome section.
- About Our College section.
- Available courses.
- Admission details.
- College facilities.
- Contact information.
- Simple and attractive design.

## 5. Available Courses

1. Computer Science Engineering
2. Artificial Intelligence and Machine Learning
3. Information Technology
4. Electronics and Communication

## 6. College Facilities

- Computer Laboratories
- Library
- Sports Facilities
- Experienced Faculty

## 7. HTML Elements Used

- html
- head
- title
- body
- div
- h1, h2, h3
- p
- ul
- li
- center
- hr

## 8. How to Run the Project

1. Open Visual Studio Code or Notepad.
2. Create a new file named `index.html`.
3. Copy and paste the HTML code.
4. Save the file.
5. Open the file in Google Chrome.
6. The College Information website will appear.

## 9. Expected Output

The website displays college information, available courses, admission details, college facilities and contact information in a simple and attractive format.

## 10. Conclusion

This project helps us understand the basic concepts of HTML and CSS. It demonstrates how to create a college information and admissions website using simple HTML elements and styling.

The website is beginner-friendly, easy to understand and useful for learning basic web development.
